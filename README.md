# Start Force One — Legal

Öffentliche Rechtstexte für die App **Start Force One** (`com.startforce.one`), gehostet via
GitHub Pages.

- `index.html` — Privacy Policy (English, für den Play Store maßgeblich)
- `de.html` — Datenschutzerklärung (Deutsch)

Die maßgeblichen Quellfassungen (Markdown) liegen im privaten App-Repo unter `docs/PRIVACY*.md`;
diese HTML-Dateien sind die veröffentlichte Spiegelung. Bei Änderungen beide Seiten nachziehen.

## Veröffentlichte URL

Nach Aktivierung von GitHub Pages (Settings → Pages → Branch `main` / `/root`):

- Privacy (EN): `https://<user>.github.io/<repo>/`
- Datenschutz (DE): `https://<user>.github.io/<repo>/de.html`

Die EN-URL kommt in die Play Console (App content → Privacy policy).
